This post marks the completion of my first week of my 2 week work placement at UCL ARC. A lot of knowledge was gained in this first week!

## Project Overview ##
My project title is "Quality of open Source Software". This project focuses on analysing different open source softwares that ARC are working on and checking the quality of documentation so that it is presented clearly for people to understand. We aim to check the following criteria: 
- Do they have a licence?
- Does a ReadMe exist?
- Is there a ReadMe Description and is it detailed enough?
- Does the ReadMe include how to install the repository?
- Does the installation steps actually work?
- Does the ReadMe include how to ask for help?
- Does it say how to contribute?
- Does it specifify anything on GenAi contributions?
- Does it say how to cite the project? 
- Is the DOI included in the citation?
- Does the project maintain a change log?
- Is the project linked to a code of conduct?

All of the above are common criteria that you see in quality ReadMe's and so the aim of my project is the make sure we can maintain this standard across the open source projects at UCL
